# Flo Faction AI Studio Suite & Cinematic Video Pipeline

Complete autonomous content creation, 4K film-grade video generation, and multi-platform social media distribution engine.

## Directory Structure
- `scripts/content_generator.py` - Daily TikTok/Reels content planning & script generation
- `scripts/asset_generator.py` - Visual asset & thumbnail generator
- `scripts/video_engine.py` - HyperFrames video production engine
- `scripts/social_poster.py` - Multi-platform auto-posting engine (TikTok, Facebook Reels, YouTube Shorts, Instagram)
- `videography/engines/cinematic_engine.py` - 4K Film-Studio Quality video engine (MiniMax Hailuo AI, Leonardo Motion, ElevenLabs, Edge TTS)

## Usage Commands
1. **Generate Daily Content**:
   ```bash
   python3 scripts/content_generator.py --date 2026-07-25
   ```
2. **Generate Visual Assets**:
   ```bash
   python3 scripts/asset_generator.py --prompt "Cyberpunk AI Agent Skyline"
   ```
3. **Render Cinematic Video Preview**:
   ```bash
   python3 scripts/video_engine.py --demo
   ```
4. **Execute Multi-Platform Social Posting Cycle**:
   ```bash
   python3 scripts/social_poster.py --cycle
   ```
