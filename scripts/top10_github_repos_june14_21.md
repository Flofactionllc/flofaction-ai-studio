### [00:35 - #10: IBULIX UI SKILLS (`ibulix/ui-skills`)]
> *"Starting at number 10: **Ibulix UI Skills**.*
> 
> *If you've ever asked an AI coding agent to build a beautiful user interface, you know exactly what the struggle feels like. The AI produces something functional, but generic: overly rounded corners, standard spacing, predictable layouts that all look the same.*
> 
> *UI Skills is a collection of specialized design skills for AI coding agents. Think of it as a comprehensive training manual for your agent.*
> 
> *Your agent routes to the right skill set for your specific design task—whether that's baseline UI structure, motion design, or responsive layouts. The setup is remarkably simple: you run `npx ui-skills` in your terminal and it loads the appropriate skill definitions into your agent. Claude Code, Cursor, Codex—whatever agent you use—suddenly has access to battle-tested design patterns organized by category and ready to apply."*
